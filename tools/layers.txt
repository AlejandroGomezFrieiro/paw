# The layers of the runtime (runtime/lua/paw), from low to high, and the
# modules in each layer. tools/layers.lua reads this file: a module reads
# the modules of its own layer and of the layers below it, and a reference
# to a higher layer must be on tools/layers-allowed.txt.
#
# - `[name]` starts a layer.
# - `paw.x` puts the module paw.x in the layer.
# - `paw.x.*` puts each module under paw.x in the layer (paw.x.y,
#   paw.x.y.z). A line for the module itself wins.
#
# A new module gets a line here. When a module moves or splits, move or
# add its line. .claude/skills/paw-code/layers.md tells what each layer
# holds.
