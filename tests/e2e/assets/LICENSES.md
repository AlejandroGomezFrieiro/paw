file was read on its source page on 2026-11-21. The files are small. They
are in the repository, and the scenarios need no network.

The titles and the names are as the source pages give them.

To add a file, take it only from a page that states the public domain or
CC0 for it. Add its line here, with the date that you read the page. A
file larger than about 100 KB does not go in the repository. Fetch such a
file with a script that checks its sha256, in a step before the run.
