# Flaky tests in quarantine (AGENTS.md, "How to work", and the skill
# paw-code, part 7).
#
# One line for each test: the full name of the test, a tab, and the fix
# that it waits for, in words (no ticket id), for example:
#
#   the vocal editor selects a phrase	the vocal editor fix
#
# A Rust test's name is its binary id and its name as nextest prints them
# (paw-core::it model::a_test), and the test has
# #[ignore = "quarantine: <the fix>"] (tools/testlint.lua checks both).
#
# The Lua runner (tests/suite.lua) runs a listed test and prints
# "quarantined" for its failure, and the run does not fail. A listed test
# that passes is reported, so that its line can go when the fix is merged.
# A line with no fix fails the run. tests/tools/quarantine.sh runs and
# reports the Rust tests. The list only gets shorter: when the fix is
# merged, remove the line.
