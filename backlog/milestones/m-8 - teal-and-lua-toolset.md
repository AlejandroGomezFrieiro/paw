## Description

A complete, reproducible toolset for paw's Teal and Lua, like cargo for Rust: build/check (cyan), format (cerulean for Teal, StyLua for Lua), test (tested), lint (luacheck or selene for Lua), language servers (teal-language-server, lua-language-server), all in the Nix dev shell and in nix flake check.
