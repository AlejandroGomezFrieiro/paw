## Description

The Rust architecture review's findings (backlog/docs/designs/architecture-review.md): a narrower Session and a paw-model crate, one source for data shapes, a DeviceProvider trait instead of closures, a narrower paw-core API, split shared state and native features, plugin format folders, a shared measure crate, a non-blocking take stop, typed extension registries, manifest needs, an API lock. Starts after the milestones in progress (m-2, m-3, m-4, m-9) are finished.
